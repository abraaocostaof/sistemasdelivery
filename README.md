# Qi Delícia - Landing Page Premium de Alta Conversão 🚀

Uma landing page profissional, moderna e de altíssima conversão criada originalmente para o sistema de delivery **Qi Delícia**. Este projeto foi desenvolvido com foco total em experiência do usuário (UX), responsividade mobile e otimização extrema para mecanismos de busca (SEO) e motores de Inteligência Artificial (AI Search).

---

## ✨ Recursos Destacados

### 📱 Experiência Mobile de Alta Performance
- **Carrossel Mobile de Planos**: No mobile, a lista de planos de assinatura é reordenada automaticamente em um slide/carrossel horizontal nativo com CSS `scroll-snap`.
- **Efeito Visual "Peek"**: Exibe parte do card lateral na tela para guiar o usuário de forma intuitiva a fazer o deslize lateral (*swipe*).
- **Indicadores Dinâmicos (Dots)**: Marcadores de página sob o carrossel que indicam a tela ativa e realizam rolagem automática suave ao serem clicados.

### 🤖 Otimização para IAs e Motores de Busca (SEO & GEO)
- **JSON-LD Schema em Grafo (`@graph`)**: Estruturado para que assistentes de IA (como ChatGPT, Gemini, Claude, SearchGPT) e buscadores (Google, Bing) localizem e respondam a consultas de usuários com facilidade. Inclui marcações semânticas para:
  - `WebSite`: Metadados do site.
  - `Organization`: Detalhes da **AC Agência Digital** e contato WhatsApp.
  - `Course`: Especificações do Curso Clone do iFood.
  - `Product`: Informações sobre os pacotes de Franquia e Código-Fonte.
  - `FAQPage`: Perguntas e respostas estruturadas.
- **SEO Semântico**: Tags Open Graph completas, Twitter Cards e marcação HTML semântica estruturada.
- **GEO Meta Tags**: Tags de geolocalização (`geo.region`, `geo.position`, `ICBM`) calibradas para indexação local e regional do Brasil e Maranhão (São Luís).
- **FAQ Interativo**: Seção acordeão de perguntas frequentes integrada com JavaScript dinâmico para responder a dúvidas comuns dos clientes diretamente na página.
